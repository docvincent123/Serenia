# Оновлення SOLVIA без Play Market

Перший робочий APK має пакет `com.quremed.solvia` і постійний ключ власника. Попередні `.test` APK — окрема тестова програма з іншими підписами. Їх не можна перетворити на робочий пакет встановленням поверх; перед переходом потрібно передати записи тестової програми на сервер. Наступні робочі APK встановлюються поверх попередньої версії та зберігають дані.

Ключ не зберігається у git і не публікується. Резервна копія ключа та реквізитів підпису належить власнику. Зберігайте її приватно: без цього ключа неможливо випустити сумісне оновлення. CI створює unsigned release APK. Власник підписує його `tools/sign-mobile-release.py`, передаючи приватні `--keystore`, `--credentials`, шлях Android SDK та каталог результату. Кожен випуск повинен мати більший `versionCode`. Для автоматичного підпису у довіреному GitHub workflow вже передбачені secrets `SOLVIA_ANDROID_KEYSTORE_BASE64`, `SOLVIA_ANDROID_KEYSTORE_PASSWORD`, `SOLVIA_ANDROID_KEY_ALIAS`, `SOLVIA_ANDROID_KEY_PASSWORD`; цей етап не виконується у pull request.

Адміністратор відкриває на ПК «Налаштування центру → Оновлення Android», вибирає `release.json` та підписаний `SOLVIA-Android.apk` із ZIP випуску й натискає «Опублікувати оновлення телефона». APK і опис зберігаються на сервері поза каталогом інтерфейсу. У Linux це `/var/lib/solvia/mobile-updates`; у Windows — `%ProgramData%/QureMed/Solvia/mobile-updates`. Шлях можна перевизначити `SOLVIA_MOBILE_UPDATE_DIR`. Встановлення/оновлення сервера не видаляє цей каталог. Максимальний APK — 8 МБ. Публікувати може лише адміністратор; завантажувати — авторизовані працівники.

Телефон після входу й під час подальших перевірок пропонує «Доступне оновлення SOLVIA». «Пізніше» відкладає автоматичну пропозицію на добу. Ручна перевірка — у налаштуваннях підключення, кнопка «Оновлення SOLVIA». Програма перевіряє розмір, SHA-256, назву пакета, versionCode та збіг підпису зі встановленим APK. Завантаження йде тільки з того самого сервера з авторизацією, без переходу за зовнішніми перенаправленнями.

Після натискання «Оновити» Android просить дозволити встановлення з SOLVIA та підтвердити заміну програми. Це звичайне системне підтвердження; тихе встановлення на особистих телефонах не використовується. Клінічна форма не переривається пропозицією оновлення. APK лежить у приватному кеші, а встановлювач отримує тимчасовий дозвіл читання лише перевіреного файла.

Новий APK стає доступним лише після оновлення серверної програми до версії з цими API та публікації випуску адміністратором. Нічого не публікується в Play Market.
