# SOLVIA Табло — концепція наступного модуля

Статус: план, ще не реалізовано.

## Екран Android Smart TV

Повноекранна локальна вебсторінка /tv на сервері центру, без окремої бази даних.
Телевізор підключений до тієї самої мережі, що й SOLVIA. Для першого варіанта
достатньо браузера телевізора; сумісність, повноекранний режим та автозапуск
перевіряються на конкретній моделі. За потреби наступним кроком — Android TV оболонка.

Угорі — емблема, назва центру, дата, день тижня та живий годинник за часовим поясом
центру Europe/Kyiv. Основна частина — великі рядки: час, ПІБ пацієнта,
ПІБ психолога, кабінет і статус. Окремо виділяється поточний виклик
«Запрошуємо до кабінету». Довгі списки автоматично перемикаються сторінками;
плавна поява рядків та коротке підсвічування нового виклику, без постійного миготіння.
Унизу — повідомлення реєстратури, наприклад про зміну кабінету.

Показувати сьогоднішні найближчі записи; скасовані та завершені прибирати.
Груповий прийом має показувати всіх учасників окремими рядками або назву групи.
Повний ПІБ чи ініціали налаштовує адміністратор для конкретного екрана.

## Інтеграція

Джерело даних: наявні appointments, attendees, patients, users і кабінети.
Браузер читає окремий обмежений TV API; прямого доступу до PostgreSQL у телевізора немає.
API повертає лише поля табло, без телефонів, діагнозів, консультацій та нотаток.
Зміна запису в реєстратурі автоматично з'являється на TV після наступного оновлення,
орієнтир — кожні 10 секунд. Час синхронізується із сервером.

Виклик на табло має запускатися явною дією «Запросити» з наявного робочого процесу;
саме настання часу запису не означає, що психолог уже готовий.

## Керування в Server Console

Розділ «TV-табло»: додати екран, прив'язати його одноразовим кодом,
обрати кабінети/поверх/психологів, формат імен, повідомлення та тривалість сторінки.
Окремий відкличний ключ пристрою має право лише читати потрібний розклад.
Пароль адміністратора на телевізорі не зберігається; ключ не передається в URL.

Якщо мережа зникла, сховати попередні ПІБ та виклики, показати
«З'єднання із сервером втрачено». Після відновлення — автоматично отримати свіжий розклад.
Порожній день: «На сьогодні прийомів немає».

## Перевірки перед використанням

- Реальний Android TV: читабельність із відстані, керування пультом, відсутність обрізання країв.
- Створення, перенесення та скасування запису відображаються без перезавантаження сторінки.
- Поточний виклик, групові прийоми, зміна дати опівночі, довгі імена та багато сторінок.
- Відкликаний/відсутній ключ не отримує розкладу; TV-ключ не має доступу до інших API.
- При збої мережі немає застарілих персональних даних на екрані.
