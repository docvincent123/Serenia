# Приймання SOLVIA 0.2

Автотест `tests/integration.py` запускає справжній C++ сервер у тимчасовій папці. Використовує лише синтетичні дані.

Перевіряє:
- авторизацію всіх чотирьох ролей, заборону анонімного доступу, анулювання сесії;
- створення сім’ї, пацієнтів, другого психолога;
- ізоляцію пацієнтів психологів, навіть у межах однієї сім’ї;
- заборону реєстратору створювати працівників та читати статистику;
- відсутність приватних нотаток у відповіді реєстратору й адміністратору;
- заборону керівнику читати картки та детальний календар;
- перевірку дати, дубль пацієнта, конфлікти розкладу, вільні слоти;
- нотатку психолога, зміну статистики керівника;
- групову консультацію, індивідуальні нотатки й завершення групи;
- перенесення та скасування, заборону змін уже проведених записів;
- одноразову анкету, валідацію відповідей, збереження результату;
- паралельне бронювання: один успіх, один конфлікт;
- збереження консультацій після перезапуску сервера.

Windows smoke-test `tests/windows-ui.ps1` запускає реальний сервер і `Solvia.exe`, перевіряє створення WebView2-вікна та зберігає контрольний screenshot. Перед цим CI перевіряє, що Vite створив `frontend/dist/index.html`.

Ручний наскрізний сценарій релізу: реєстратор створює пацієнта → записує його до психолога → психолог бачить свій запис і пацієнта → відкриває картку → зберігає консультацію, цілі, наступний план і домашнє завдання → реєстратура не бачить приватний текст → керівник бачить лише зміну агрегованої статистики.
