# SOLVIA Android 3.3.1 (код 38)

Прибрано стрілки «Назад» із заголовків, старий повноекранний список меню та зайві підказки про завершення роботи, очікування синхронізації і прибуття пацієнта. Основна навігація — бокове меню. Системна дія «Назад» із профілю повертає до консультацій, а на головному екрані згортає програму. Фактичний час останньої синхронізації залишається, якщо він відомий. Непередані записи зберігають індикатори й доступ до стану передавання.

Сервер/Windows 2.5.0 повторно оновлювати не потрібно. Android 3.3.1 встановлюється поверх робочого 3.3.0 / 3.2.2 із тим самим підписом через пакет APK + release.json.
