# SOLVIA 3.1.0

Одна версія продукту: сервер, Windows, Linux, Server Console, React UI та Android — 3.1.0.
Android використовує versionCode 42 (попередній пакет 3.3.4 мав код 41).
Менший видимий номер Android є навмисним вирівнюванням назв; для встановлення поверх
старого пакета потрібні вищий код та той самий підпис. Дані додатка видаляти не потрібно.

Версія відображається на вході, у меню SOLVIA, налаштуваннях і заголовку Server Console.
Окремо консоль показує фактичну версію підключеного сервера з /api/health:
оновлений клієнт не видає старий сервер за 3.1.0.
Windows EXE має також FileVersion/ProductVersion 3.1.0 у властивостях файла.

## Прокручування Server Console

Основний робочий простір блокує прокручування body. Консоль тепер має власну
область висотою вікна з overflow-y: auto. У короткому вікні можна дістатися
останніх полів та кнопок публікації оновлень, налаштувань і списку пристроїв.

## Встановлення

Після успішних CI-збірок встановіть сервер і клієнти 3.1.0 звичними інсталяторами,
зі збереженням наявної PostgreSQL та налаштувань. Android APK встановлюйте поверх
попереднього з тим самим підписом; для роздачі використовуйте відповідний release.json.
TV-модуль додає таблиці для підключення екранів і викликів, зі збереженням наявних даних та сеансів.

Вбудована сторінка /tv для Chrome на Smart TV, рухома стрічка новин та TV API описані в [TV-DISPLAY.md](TV-DISPLAY.md).
