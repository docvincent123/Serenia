# SOLVIA Android 3.3.2 (код 39)

Вкладки консультацій мають назви «Активні» й «Архів» без лічильників. Компактний індикатор «Онлайн / Офлайн» перенесено праворуч у верхню панель замість емблеми. Натискання відкриває стан передавання; повні деталі доступні також для озвучення та за довгим натисканням. Емблема робочого інтерфейсу залишилася в боковому меню, унизу якого додано QureMed Industries.

Сервер/Windows 2.5.0 повторно оновлювати не потрібно. Встановіть Android-пакет поверх робочого 3.3.1 / 3.3.0 / 3.2.2 із тим самим підписом через APK + release.json.
