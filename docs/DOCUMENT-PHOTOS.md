# Фото документів і прийоми в React SOLVIA

У картці пацієнта відкрийте «Документи» → «+ Документ» → «Фото паперового документа». Завантажте JPEG/PNG, поверніть або обріжте поля. Обробка покращує контраст; це не автоматичне виправлення перспективи. Український та англійський друкований текст автоматично розпізнається і потрапляє в поле тексту документа. Перевірте результат, ПІБ підписанта і наявність підпису на папері, після чого збережіть документ. Рукопис може розпізнаватися неточно.

Зберігаються дві окремі JPEG-копії: кольорове фото і оброблений скан. Копії обмежені до 2400 px по довшій стороні; вихідний файл із метаданими не архівується. Підтримується одне фото на документ, до 20 МБ / 60 Мп. HEIC та багатосторінкові PDF не підтримуються цим завантажувачем.

OCR працює в локальному Web Worker із мовними пакетами, що постачаються разом з інтерфейсом; CDN і зовнішні сервіси не потрібні. Підготовка цих ресурсів виконується перед `npm run build` і `npm run dev`. CSP дозволяє локальні workers і WebAssembly, без загального `unsafe-eval`. Сесійні права і доступ до документів перевіряє сервер. Додавання паперового документа не створює цифровий підпис.

Таблиця прийомів містить час, пацієнта, психолога/кабінет, статус, очікування та швидкі дії. Фільтр стану відрізняє очікуване прибуття, пацієнтів у центрі та консультації. Очікування рахується лише після прибуття і до початку консультації; від 15 хвилин виділяється кольором. На вузькому екрані прокручується сама таблиця.

## Перевірка

```bash
npm --prefix frontend ci
npm --prefix frontend run build
node --test tests/shift-workspace.mjs tests/booking.mjs
node tests/document-photo-ui.cjs
```

Для браузерного тесту потрібен Playwright/Chromium; підтримуються `SOLVIA_PLAYWRIGHT_MODULE` і `SOLVIA_CHROMIUM_EXECUTABLE`. Тест використовує синтетичні дані, перевіряє розпізнавання двох мов, CSP worker, відсутність зовнішніх запитів, фільтри, прибуття і вузьку таблицю. Серверні інтеграційні перевірки в `tests/integration.py` перевіряють збереження фото, відхилення некоректних даних та межі доступу. Оновлення схеми додає поля до існуючої таблиці без видалення цифрових документів.
