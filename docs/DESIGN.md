# SOLVIA Mint Workspace

Візуальний стиль перенесено з моушн-презентації SOLVIA у наявний нативний Windows-клієнт.

| Елемент | Значення |
|---|---|
| Фон | `#F3F3E9` |
| Текст і бічна панель | `#112C2B` |
| М’ятний акцент | `#A7EDCF` |
| Картки й поля | `#FFFFFC` |
| М’яке виділення | `#D3EFDF` |
| Другорядний текст | `#697F74` |
| Шрифт | системний Segoe UI |

Оновлено вхід, навігацію з лінійними піктограмами, статистичні картки, шапки й рядки таблиць, форми, кнопки з реакцією на наведення та порожні списки. Панель дій переноситься на наступний рядок, якщо ширини вікна бракує. Кнопка виходу прив’язана до нижньої частини панелі. Поля, списки та кнопки залишаються нативними; клавіатурна навігація й багаторядковий ввід збережені.

Статистика в огляді походить із наявного `/api/stats`, демо-цифри з ролика не використовуються. HTTP-запити, перевірка доступів і сховище даних не змінювалися.

У цьому репозиторії реалізовано Windows-клієнт на C++/Win32. Android- і Linux-клієнтів у цій версії вихідного коду немає, тому цей редизайн стосується Windows.

Перевірка Windows виконується штатним GitHub Actions: збірка MSVC, інтеграційні перевірки API, вхід/навігація/вихід для чотирьох ролей та контрольні знімки справжнього нативного вікна. Знімки доступні в артефакті `SOLVIA-native-UI-check` відповідного запуску.
