# Lemvori Care для Linux

Lemvori Care використовує нативні вікна Qt Quick. Обидва застосунки підключаються через HTTPS до тієї самої бази центру через наявний API.

| Застосунок | Роль | Робота |
| --- | --- | --- |
| Lemvori Care · Реєстратура та керівник | Реєстратура | Пошук і створення картки, вибір психолога й кабінету, вільні години, підтвердження запису, прибуття пацієнта, календар і психологи на зміні. |
| Lemvori Care · Реєстратура та керівник | Керівник | Зведення за місяць, стан психологів, перегляд виписок, погодження або повернення з причиною. |
| Lemvori Care Admin | Адміністратор | Працівники й ролі, кабінети, напрямки, зміни, доступ реєстратури, правила запису, дані центру, сеанси, журнал, стан сервера та резервні копії. |

Після встановлення відкрийте потрібний ярлик. На екрані входу виберіть «Файл центру» і відкрийте файл `.solvia` або введіть HTTPS-адресу. Програма перевіряє TLS і запам’ятовує ідентифікатор сервера. Сертифікат локального CA має бути довіреним у системі. Психологи використовують Android.

Щоб записати пацієнта, відкрийте «Пацієнти», знайдіть картку й натисніть «Записати». Оберіть психолога, кабінет, дату, тривалість і вільний час. Сервер повторно перевірить доступність при підтвердженні.

Вкладка «База та копії» виконує створення та відновлення копій через локальний `solvia-admin` після перевірки прав ОС. На серверному ПК відкрийте Admin з локальною HTTPS-адресою. Для відновлення виберіть `.dump` і введіть «ВІДНОВИТИ».

## Встановлення та перевірка

GitHub Actions **Lemvori Care native Linux** збирає пакет у `lemvori-care-native-linux-x64`. Розпакуйте ZIP і виконайте:

```bash
sudo apt install ./solvia-native_3.2.0~preview3_amd64.deb
```

Пакет встановлює два ярлики та Qt-клієнт для Ubuntu 24.04 amd64 і сумісної бази Linux Mint. Встановлення не мігрує PostgreSQL. Перед використанням у центрі перевірте обидва ярлики, з’єднання з CA, реєстрацію, запис із вибором часу, надходження прийому в Android і рольові обмеження на тестових даних.

Поточний нативний пакет має статус preview. Повна картка з документами, сімейні й групові прийоми, перенесення, черга очікування, супервізії, TV-виклики та офлайн-редагування ПК ще потребують перенесення або перевірки в Qt. Для цих сценаріїв збережіть доступ до наявної програми.

Розробка потребує CMake, компілятора C++20, Qt 6.4+ та модулів QML, перелічених у `.github/workflows/native-qt-linux.yml`.

```bash
cmake -S native/linux -B build/native-linux -DCMAKE_BUILD_TYPE=Release
cmake --build build/native-linux --parallel 2
./build/native-linux/solvia-native
./build/native-linux/solvia-native --admin
```
