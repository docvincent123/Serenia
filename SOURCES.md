# Фактчек: камера смартфона й невидимий сигнал пульта

Дата перевірки джерел: 30 жовтня 2026. Це тема для пробного освітнього ролика, **не підтверджений актуальний тренд**. Популярність, пошукові обсяги й статистику платформ не перевіряли.

## Оцінка теми

Універсальний предмет — телефон і телевізійний пульт. Дія відтворюється без спеціального обладнання; є швидкий візуальний результат і зрозуміле пояснення. Головний ризик сценарію — обіцяти результат для кожного смартфона або показати художню анімацію як власноруч проведений дослід.

Рекомендований хук: **«Камера телефона іноді бачить те, чого не бачать очі».**

English: **“Some phone cameras can see light your eyes can’t.”**

Слова «іноді», «деякі» або «може» потрібні. Заголовок «Будь-який телефон бачить невидиме» — некоректний.

## Твердження та межі

| Твердження | Як використати |
| --- | --- |
| Багато телевізійних пультів передають команди інфрачервоним світлом | Казати «інфрачервоний пульт» або «багато пультів», а не «кожен пульт». Bluetooth/RF-only моделі можуть не випромінювати такого сигналу. У гібридної моделі ІЧ може працювати лише для частини кнопок. |
| Ближнє інфрачервоне світло звичайно не видно людським оком | Достатньо фрази «невидимий інфрачервоний сигнал». Точну довжину хвилі для невідомої моделі не називати. Червоний видимий індикатор на корпусі пульта — не те саме, що ІЧ-випромінювач. |
| Кремнієві сенсори камер можуть бути чутливими до ближнього ІЧ | Камерний модуль, його фільтр і обробка зображення визначають результат. Не всі смартфони й не всі камери одного смартфона покажуть сигнал. |
| ІЧ-фільтри зменшують чутливість до такого світла | Підтверджено офіційною документацією Raspberry Pi для їхніх камер. Це пояснення загального принципу; це не випробування конкретного телефона. Не радити знімати фільтр або розбирати смартфон. |
| На екрані сумісної камери натискання кнопки ІЧ-пульта може виглядати як світлий/білуватий/фіолетовий спалах | Колір на дисплеї залежить від камери й обробки. Це не «справжній колір інфрачервоного» для ока. Не обіцяти саме фіолетовий. |
| Фронтальна камера іноді показує ІЧ, коли основна його пригнічує | Порада «спробуй фронтальну камеру» допустима з уточненням: результат не гарантовано. Також можна спробувати інший завідомо ІЧ-пульт/камеру. |
| Відсутність спалаху не доводить поломку пульта | Причиною може бути фільтр камери, тип зв’язку пульта або вибрана кнопка. Не подавати дослід як безпомилкову діагностику. |

## Що не можна стверджувати

- Звичайна камера стала тепловізором, бачить температуру тіла або тепло крізь стіни.
- Телефон отримав рентген, нічне бачення без освітлення чи «секретний режим» через додаток.
- Будь-який смартфон обов’язково покаже ІЧ.
- Фіолетовий у відео — природний видимий колір ІЧ.
- Ролик демонструє реальний експеримент автора, якщо використано лише CGI. Для CGI потрібна помітка «Ілюстрація»; для реального показу — власний запис саме обраних камери та пульта.

Не спрямовувати у камеру лазери та не використовувати Сонце як «джерело ІЧ» для цього досліду. Звичайного побутового пульта достатньо.

## Доступні й фактично прочитані джерела

Мережевий доступ обмежений. Використано успадкований проксі з увімкненою перевіркою TLS; обхід обмежень не застосовувався.

1. **Raspberry Pi — офіційна документація, “IR filter”.**
   - Фактично прочитано: https://raw.githubusercontent.com/raspberrypi/documentation/master/documentation/asciidoc/accessories/camera/ir-filter.adoc
   - Зафіксована версія репозиторію: https://github.com/raspberrypi/documentation/blob/7376533ab86ea07acc77ef6a9f3c3e57fcff833d/documentation/asciidoc/accessories/camera/ir-filter.adoc
   - Короткий перевірений уривок: “contain an IR filter to reduce the camera's sensitivity to infrared light”.
   - Підтверджує принцип ІЧ-фільтра в описаних виробником камерах, не сумісність будь-якого смартфона. Далі джерело описує фізичне видалення фільтра; цей процес у ролику не потрібний.

2. **Arduino-IRremote — README авторів бібліотеки передавання/приймання ІЧ-сигналів.**
   - Фактично прочитано: https://raw.githubusercontent.com/Arduino-IRremote/Arduino-IRremote/master/README.md
   - Зафіксована версія: https://github.com/Arduino-IRremote/Arduino-IRremote/blob/c4ec014400ccf5a8b3678d5f33e4cc17eca29d23/README.md
   - Короткий перевірений уривок: “A library enabling the sending & receiving of infrared signals.” Документ містить протоколи телевізійних ІЧ-пультів.
   - Це первинне технічне джерело про ІЧ-протоколи; не виробник смартфонів і не доказ сумісності конкретної камери.

## Довідкове джерело, яке НЕ було доступне для прочитання

- **Sony Support, article 00025283**, відома довідка про перевірку ІЧ-пульта камерою: https://www.sony.com/electronics/support/articles/00025283
- Статус: **не прочитано в цій сесії**; домен Sony не входить до дозволеної мережевої політики. Актуальний текст, заголовок і перелік сумісних пристроїв тут не підтверджені. Не подавати це посилання як фактично перевірене.

Телефон-специфічні нюанси в цьому документі — обережні загальні рекомендації, а не сертифікація певної моделі. Для кадру з реальним телефоном потрібна коротка практична перевірка на вибраному обладнанні.

## Чернетка озвучення, приблизно 25–30 секунд

«Камера телефона іноді бачить те, чого не бачать очі. Наведи інфрачервоний пульт у камеру й натисни кнопку. На деяких телефонах видно світлі спалахи. Це сигнал, яким пульт передає команду телевізору. Не видно? Спробуй фронтальну камеру. Результат залежить від камери та пульта — це не тепловізор».

Постійний короткий титр на демонстрації: **«Працює не з кожною камерою та пультом»**.

Для швидкої версії достатньо показати аватара, телефон/пульт, умовну стрілку ІЧ та світлий спалах на дисплеї. Промінь у повітрі — тільки схематична анімація, позначена «Ілюстрація». Сигнал не має виглядати як видима лазерна лінія в реальній кімнаті.
