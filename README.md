# LumoLab: невидиме світло / Invisible Light

Окрема медіагілка для завантаження першого ролика LumoLab; не оновлення SOLVIA.

Вертикаль 1080×1920, H.264, 24 fps, AAC 48 kHz. Субтитри вбудовані; окремі SRT лежать поруч.

Оригінальний 3D-аватар Lumo змодельований у Blender. Рух рота реагує на звук; це стилізований віртуальний ведучий. Голос локально синтезований eSpeak NG, роботизований, не клон голосу реальної людини. Графіка, електронний фон і переходи оригінальні.

Демонстрація з пультом і камерою є позначеною схематичною ілюстрацією. Результат залежить від ІЧ-фільтра камери та типу пульта; це не тепловізійне зображення й не бачення крізь стіни. Фізичний експеримент на конкретному телефоні не проводився. Перевірені технічні джерела й межі перевірки: [SOURCES.md](SOURCES.md).
